# 训练与状态机

版本1面向已经完成风险问答的成人一般运动；不自动生成临床康复方案。
默认每周3次，每次 min(12,可用分钟)，RPE 3。用户周上限可为0；周日程优先顺序为周一、周四、周六、周二、周五、周三、周日，去掉不可用日再截取上限。不为漏练补课。新手不直接追求公共健康推荐的周总量。

分钟层先分配活动/热身放松（总时间30%，最多4分钟），再分配剩余的有氧与力量。常规力量占剩余50%，耐力目标30%，增肌目标65%；不足10分钟不加力量，相邻日避免重复力量刺激。全部动作时段含休息，不额外增加组数。步数是已有活动基线，不是与训练叠加的新负荷；未知时为null。

| 转换 | 明确条件 |
|---|---|
| INIT→ADAPTATION | 已有前一天或更早的训练反馈 |
| ADAPTATION→PROGRESS | 适应至少14天、近30天至少4条训练记录、confidence≥0.5 |
| PROGRESS→PLATEAU | 本轮PROGRESS至少21天，执行率与覆盖≥0.85，仅使用进入本轮后的同一测试连续3周每周≥2个样本、表现范围≤2% |
| PLATEAU→DELOAD | 平台保持至少7天 |
| 任意非减量阶段→DELOAD | 当前高疲劳/严重酸痛，或多日恢复差伴连续完成率下降 |
| DELOAD→PROGRESS | 至少7天、近7天至少3次良好恢复、最新记录也良好 |

平台开始仅替换有氧动作变体，保持时长与强度，不同时增加训练量。换动作不保证解决平台，7天后按规则减量复评。未记录标准化表现时，不臆测平台。

公共健康参考：[美国身体活动指南第2版](https://www.cdc.gov/physical-activity/media/pdfs/Physical_Activity_Guidelines_2nd_edition.pdf)，成人一般长期方向包括每周150分钟中等强度有氧和每周2天力量活动；该总体目标不是本引擎给所有用户的起始剂量。访问日期2026-10-09。本项目12分钟起步、分配比例及状态阈值均为产品启发式，非该指南验证的个体处方。
